## 关于本站

本站使用 **Astro** 构建，主题是 [Firefly](https://github.com/CuteLeaf/Firefly)，它基于 [Fuwari](https://github.com/saicaca/fuwari) 二次开发。选择它的原因是：静态生成、打开够快，而且 Markdown 写作体验很舒服。

站内目前支持：

- Markdown / MDX 写作，支持 KaTeX 数学公式、Mermaid 与 PlantUML 图表
- 站内搜索（Pagefind）与 RSS / Atom 订阅
- 亮色 / 暗色主题与响应式布局
